Pengaturan Stream

Harap isi judul stream.
Pilih video untuk streaming.
Stream key diperlukan.
Ambil di YouTube Studio > Live > Stream > Stream key.
Kosongkan = otomatis (2500 kbps).
Stream prioritas terendah dihentikan dulu saat memori hampir penuh.
Kosongkan = langsung mulai.
0 = tidak berhenti otomatis. Maks 2880 menit (48 jam).

Cara Menggunakan

  1. Upload video dari Google Drive di halaman Upload Video.
  2. Salin Stream Key dari YouTube Studio (Live > Stream).
  3. Isi judul, pilih video, tempel stream key, lalu klik Mulai Streaming.
  4. Pantau status siaran di Live List.

Tips Singkat

  • Kosongkan bitrate = kualitas otomatis.
  • Kosongkan jadwal = mulai seketika.
  • Durasi 0 = streaming tanpa batas waktu.
  • Jika streaming mati, aplikasi mencoba restart otomatis (maks 3x per 10 menit).
